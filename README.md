# Maheen Shaikh Portfolio

Responsive portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html`: page structure and portfolio content
- `style.css`: responsive layout and visual styling
- `script.js`: mobile navigation, current year and scroll reveal

## Run locally
Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.
